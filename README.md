# Fernhunt Baltic AI

Strona informacyjna projektu Fernhunt Baltic AI.

## Struktura

| Plik | Zawartość |
|---|---|
| `index.html` | Strona główna (jedna strona, sekcje z kotwicami) |
| `styles.css` | Style, kolory marki, responsywność |
| `favicon.svg` | Ikona robocza, nie zatwierdzone logo |

Strona jest statyczna. Nie wymaga builda ani zależności.

## Podgląd lokalny

```bash
python3 -m http.server 8000
```

Następnie otwórz `http://localhost:8000`.

## Do uzupełnienia przed publikacją

1. Adres kontaktowy w sekcji `#kontakt` w `index.html` (instrukcja w komentarzu HTML).
2. Zatwierdzone logo w miejsce znaku roboczego.
3. Dane podmiotu w stopce po rejestracji.
4. Polityka prywatności, jeśli pojawi się formularz lub analityka.

## Zasady treści

- Nie przedstawiać projektu jako funduszu inwestycyjnego.
- Nie obiecywać kapitału, zysku ani finansowania.
- Fundację i spółkę opisywać jako planowane do czasu rejestracji.
